# Кабинет селлера · демо (Made by THOUSUKA)

Статичное демо кабинета продавца. Ничего собирать не нужно — только отдать папку как статику.

## GitHub Pages

1. Создай репозиторий и положи содержимое этой папки в его корень (файлы, не саму папку).
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту демо доступно по адресу `https://<логин>.github.io/<репозиторий>/`.

Файл `.nojekyll` обязателен — без него Pages может не отдать часть файлов.

## Что внутри

- `index.html` — карта экранов, точка входа
- 14 экранов кабинета: сводка, витрина, позиция, новая позиция, заказы, карточка заказа, расписание, финансы, аналитика, отзывы, продвижение, сообщения, профиль бренда, настройки
- `demo.css`, `demo.js` — общая обвязка демо (масштабирование макета 1600px, навигация стрелками ← →)
- `img/` — фото позиций и аватар
- `assets/` — токены дизайн-системы THOUSUKA и шрифты Lato

## Локально

Открыть `index.html` можно прямо файлом, но шрифты и `.avif` надёжнее отдаются с сервера:

```
python3 -m http.server 8080
```

Затем `http://localhost:8080/`.
